# Lista de Tarefas

Lista de tarefas feita com HTML, CSS e JavaScript. É possível adicionar, marcar como feita e remover tarefas, e os dados ficam salvos no navegador.

🔗 **Link com Erro -EM PROCESSO-:** https://isabelleassis74.github.io/lista-de-tarefas

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Adicionar tarefas (botão ou tecla Enter)
- Marcar tarefa como concluída
- Remover tarefas
- Contador de tarefas pendentes
- Tarefas salvas no navegador (localStorage)
- Layout que se adapta ao celular

## Como rodar
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## O que aprendi
- Criar elementos na página com JavaScript
- Trabalhar com arrays e objetos
- Guardar dados no navegador com localStorage
